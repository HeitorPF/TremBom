# TremBom - Serviços de entrega 

O "TremBom" é uma plataforma de serviços de entrega, projetada para conectar restaurantes parceiros e clientes, de forma semelhante ao popular aplicativo iFood.

### Descrição das tabelas
- Cliente pode realizar 0 ou muitos pedidos
- Restaurante pode aceitar 0 ou muitos pedidos
- Pedido precisa ter 1 pagamento
